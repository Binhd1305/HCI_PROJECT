Hand Gesture Scrolling
A Python application that lets users scroll using hand gestures captured through a webcam. Built with OpenCV, MediaPipe, and PyAutoGUI, it tracks hand landmarks and translates vertical index-finger movements into continuous scrolling.
Features include gesture-based activation, fist-based deactivation and exit, and a live camera interface displaying hand tracking and scrolling status. Scrolling pauses when no hand or multiple hands are detected.
This project explores touch-free computer interaction as part of Human–Computer Interaction (HCI).
